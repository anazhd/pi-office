# README artwork

- `pi-office-hero.png`: 1600 × 900 banner composited from the real app screenshot and an original pixel-art
  wordmark. The room is not an AI-redrawn approximation.
- `pi-office-screenshot.png`: cropped app scene, autumn + Halloween previews, captured with `agent-browser`.
  The browser's office API was replaced with fixture snapshots from `src/api/mock.ts` and its live SSE connection
  was blocked. No private session data was used.
- `pi-office-wordmark.svg`: original block/pixel lettering with warm gold faces and extruded shadows, inspired by
  early isometric social games. No Habbo logo, fonts or artwork were copied.
